# LUMIS

This is a forearm band with an 8*36 LED matrix, that's battery powered. 

It uses a Xiao esp32-c3, that has Wi-Fi and Bluetooth, and a snap on 3d-printed diffuser to achieve a cool lighting effect.

## Firmware

I used [WLED](https://github.com/wled/WLED) as the firmware because it provides a nice UI and support for matrices
